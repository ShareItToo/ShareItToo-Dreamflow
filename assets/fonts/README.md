# Roboto PDF fonts

`Roboto-Regular.ttf` and `Roboto-Bold.ttf` are the `web/static` artifacts from
the official Roboto v3.015 release:

- release: `googlefonts/roboto-3-classic`, tag `v3.015`
- source commit: `91d5d3e5b81efa04a77925cc609fdcdd7ee663d1`
- release archive: `Roboto_v3.015.zip`
- regular SHA-256: `1ee8483b140ddfbbb8548838935a9878a6eda018aa1c39f4bf29d65b14a052db`
- bold SHA-256: `28874d37d069dc482e8486d5db06a3fcb31ab9c38b37c210afaf14bc7b550535`

They are bundled solely for deterministic, offline financial-document PDF
generation. The corresponding SIL Open Font License 1.1 is stored at
`assets/licenses/Roboto-OFL.txt` and shipped as a Flutter asset.
